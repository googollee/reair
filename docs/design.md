# ReAir 设计

## 概述

每个节点是一块板子：ESP32-C3 模块驱动一个可反转风扇，对外是一个 Matter 设备，节点之间通过 Wi-Fi 局域网上的 IPv6 组播同步状态。所有节点运行同一份固件，角色（主、从、独立）是节点的一项设置，不是不同的程序。

节点内部分为六个模块：Matter 层、节点状态、同步、风扇驱动、联网管理、板上交互。节点状态是中心，其余模块只通过它读写状态。

## 组成与职责

```
 Matter 控制器                          其他节点
      │ Matter                              │ UDP 组播
 ┌────┴────┐      ┌──────────┐        ┌─────┴────┐
 │Matter 层├─────►│ 节点状态 │◄──────►│   同步   │
 └─────────┘      └─┬──────┬─┘        └──────────┘
                    │      │
              ┌─────▼──┐ ┌─▼────────┐
              │风扇驱动│ │联网管理  │◄── 按键
              └────────┘ └─┬────────┘
                           └──► LED
```

| 模块 | 职责 |
|---|---|
| Matter 层 | 暴露节点的 Matter 端点，把控制器的读写转换成对节点状态的读写；对从节点的受限写入返回错误；支持 Matter OTA |
| 节点状态 | 保存和仲裁全部状态：角色、各项设置、风力、当前风向、多主警告；决定实际执行的风向和风力；负责持久化；运行主节点和独立节点的往复计时 |
| 同步 | 主节点周期发送和立即发送同步报文；从节点接收报文并写入节点状态；主节点检测多主 |
| 风扇驱动 | 把实际风向和风力转换为风扇 PWM 输出，处理占空比映射和极性 |
| 联网管理 | Wi-Fi 连接与重连、蓝牙配网、IPv6 地址检查；向 LED 提供联网状态；处理按键事件 |
| 板上交互 | 一个 LED 和一个按键的底层驱动 |

## 协作方式

**用户通过 Matter 设置**：Matter 层写入节点状态。设置项持久化；角色、风向模式、周期、风力的变化立即反映到风扇驱动。节点为主时，风力或角色变化触发同步模块立即发送一次。

**主节点和独立节点的往复**：节点状态内的计时器按风向模式和周期决定当前风向。风向翻转时通知风扇驱动；节点为主时同时触发同步立即发送。

**从节点跟随**：同步模块校验报文（长度、版本、风力取值），不合法的整个丢弃；合法报文把风向和风力写入节点状态，不检查来源和顺序。节点状态根据本节点的正向风向设置，把逻辑风向换算成实际风向，交给风扇驱动。Matter 的受限写入在从节点上被拒绝，所以从节点的风向和风力只来自同步。

**风扇驱动**：节点状态把逻辑风向按正向风向设置换算成实际风向（排气或进气），连同风力档位传给风扇驱动。占空比数值和极性封装在风扇驱动内；翻转时直接切换占空比，风向翻转是瞬时的。

**联网与风扇独立**：联网管理的状态只影响 LED，不影响风扇。断网时各节点按已有状态继续运行。

**多主警告**：主节点的同步模块收到发送者不是自己的报文，就在节点状态里置警告；用户通过 Matter 清除。网络栈若回环自己发出的报文，同步模块用发送者地址排除。独立节点不接收同步报文。

**角色切换**：节点状态立即按新角色工作，新角色需要而无法确定的值沿用当前值。从节点保留自己最后保存的风向模式和往复周期，它们在从节点上不起作用。

**固件升级**：固件通过 Matter OTA 写入未运行的应用分区，校验通过后切换启动。升级不改写配对参数、配网信息和节点设置；恢复出厂设置只清除运行时数据。

**上电**：从节点风扇静止，等待同步；主节点和独立节点恢复保存的设置和风力，风向由风向模式重新决定。

## 关键接口

### Matter 层与节点状态

Matter 端点和簇的定义见 [0001](adr/0001-matter-device-model.md)。节点状态向 Matter 层提供：

| 项 | 读写 | 说明 |
|---|---|---|
| 角色、正向风向 | 读写 | 所有角色均可写 |
| 风向模式、往复周期、风力 | 读写 | 从节点写入返回错误 |
| 实际风向 | 只读 | 进气、排气、停止，已包含正向风向的影响 |
| 多主警告 | 只能清除 | 无、警告；节点置为警告，控制器只能置为无 |

### 同步

报文格式和传输见 [0003](adr/0003-sync-packet.md)。同步模块与节点状态之间：

- 发送：节点状态提供逻辑风向和风力；节点状态在风向翻转、风力变化、角色切换为主时请求立即发送，其余时间按 5 秒周期发送。
- 接收：同步模块向节点状态写入逻辑风向和风力；向主节点上报「收到他人报文」事件。

### 风扇驱动

```
set(direction: Exhaust | Intake, power: Off | Low | Mid | High)
```

`power` 为 `Off` 时输出停机点，`direction` 被忽略。风扇驱动内部处理占空比映射和极性，见 [0005](adr/0005-fan-control.md)。

### 联网管理

对 LED 提供联网状态，取值为：配网模式、配网超时、重连模式、已联网、异常。对节点状态提供按键事件：短按、长按。行为定义见 [0006](adr/0006-onboard-interaction.md)。

## 数据

| 数据 | 适用角色 | 持久化 |
|---|---|---|
| 角色、正向风向 | 全部 | 是 |
| 风向模式、往复周期、风力 | 主、独立 | 是 |
| 当前风向 | 全部 | 否 |
| 从节点的风力 | 从 | 否 |
| 多主警告 | 主 | 否 |
| Matter 配网信息、Wi-Fi 凭据 | 全部 | 是 |
| 配对参数 | 全部 | 出厂分区，只读，恢复出厂设置不清除 |

持久化范围和上电状态的依据见 [0002](adr/0002-node-state-model.md)，分区划分、配对参数和 OTA 见 [0007](adr/0007-flash-layout-and-ota.md)。恢复出厂设置清除运行时数据，回到 [0001](adr/0001-matter-device-model.md) 的默认值。
