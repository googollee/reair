# 0005 风扇控制

## 决策

### 风扇与接口

使用 ebm-papst 4412FGPR（Vario Pro 系列，可反转），12V 直接供电。风扇有三根线：+12V、GND、PWM 控制线。PWM 输入是开集电极型，频率范围 2 kHz 到 5 kHz，使用 3 kHz。没有转速反馈。板上装一个 3 位螺丝接线端子，风扇引出的裸线拧入端子，不需要焊接，线序为 +12V、GND、PWM。装配时风扇的标定风向（数据手册的 0%–50% 一侧）朝外，即低占空比为物理排气，高占空比为物理进气。

### 占空比与方向、风力

方向和转速都由 PWM 占空比决定：

- 低占空比一侧为物理排气，高占空比一侧为物理进气，由风扇的标定风向和装配方向决定，面包板实测一致。驱动层只接收实际风向（排气或进气）和风力；逻辑正向、反向与正向风向设置的换算在节点状态里完成，见 [F-004](../prd.md#f-004)。
- 中间约 45% 到 57% 为停转区，停转区有滞回，数值为面包板实测（3 kHz、12V、单台风扇，步进 1%）：低侧占空比上升到 48% 停转，下降到 45% 起转；高侧占空比下降到 54% 停转，上升到 57% 起转。停机时输出 50%，位于这一段中央。[数据手册](../reference/ebm-papst-4412fgpr-203-datasheet.pdf)第 4 页转速曲线的读图近似值约为 42% 到 58%，与实测基本相符，以实测为准。
- 风力的高、中、低三档对应占空比，每个方向各一组，面包板实测三档风力差异明显：

| 风力 | 排气（低占空比） | 进气（高占空比） |
|---|---|---|
| 高 | 5% | 95% |
| 中 | 25% | 75% |
| 低 | 38% | 62% |

### 输出电路

不直接把 GPIO 接风扇 PWM 线，而是通过 N 沟道 MOSFET 拉低控制线。成品板用贴片 2N7002，栅极串联 1 kΩ，栅极对地接 100 kΩ 下拉；面包板用直插 2N7000，电阻相同。MOSFET 使输出反相，固件对输出取反来抵消，原型实测占空比 0% 和 100% 的风向与数据手册一致。

### 方向翻转

翻转方向时，驱动层直接把占空比设到目标方向的档位，不经停机点，也不等待。面包板实测从任意占空比直接切换方向，风扇自己完成反转。风向翻转对 Matter 和同步是瞬时的，实际风向直接显示目标风向。关闭风力时输出 50%。

### 反馈

没有转速反馈，实际风向和风力是设定值，不是测量值。

## 依据

- 正向风向、风向模式、风力的取值：[F-004](../prd.md#f-004)、[F-005](../prd.md#f-005)、[F-007](../prd.md#f-007)。
- 实际风向可查看，并包含停止：[F-012](../prd.md#f-012)。
- 风扇自带驱动电路，方向和转速由一路 PWM 控制，不需要外置驱动；接线、PWM 输入类型和频率范围、占空比与方向、转速的关系见[4412FGPR-203 数据手册](../reference/ebm-papst-4412fgpr-203-datasheet.pdf)。
- 数据手册规定调速只能通过 PWM 控制线，不允许对供电电压做 PWM；开集电极输入内部有上拉，上拉电压未说明，面包板实测控制线开路电压约 5V，超过 ESP32-C3 的 GPIO 耐压，不能直接接 GPIO。
- 面包板实测：2 kHz、3 kHz、5 kHz 下噪音和风速没有可感知的差别，取允许范围中段的 3 kHz；2 kHz 与 3 kHz 的停转点、起转点相差不超过 1%，风噪很小，噪声以机械噪声为主。
- 面包板 12V 实测风扇电流（紫线占空比）：停机 50% 为 12 mA；排气 38% / 25% / 5% 为 53 / 118 / 235 mA；进气 62% / 75% / 95% 为 46 / 96 / 229 mA。三档电流递增明显，最大 235 mA 略高于手册的 200 mA。
- 低档取 38% 和 62%：离低侧起转点 45% 有 7%，离高侧起转点 57% 有 5%，留出余量。三档以 50% 为中心对称，实测风力差异明显。
- 数据手册的转速曲线显示停转区有滞回，起转点和停转点不同，停转区内的状态与占空比的来向有关；面包板实测占空比跨过停转区时，风扇自己完成加减速和反转。

### 外置 H 桥加普通直流风扇（未采纳）

普通风扇反转时风量大幅下降，且需要额外的驱动电路。

### GPIO 直接接风扇 PWM 线（未采纳）

风扇内部上拉电压未知，可能损坏 GPIO。

### 对供电电压做 PWM 调速（未采纳）

数据手册不允许。

### 翻转时先停机、等待转子停稳（未采纳）

面包板实测不需要：直接切换占空比，风扇自己完成反转。增加等待只会让往复模式的风向切换变慢。

### 用传感器闭环调节风量或周期（未采纳）

单管周期换气设备受室内外压差影响，送风和排风量不平衡，热回收效率低于标称值。Koper 的[论文](https://doi.org/10.3390/en17225801)在真实工况（室外约 5℃，压差约 7.4 Pa）下比较了两种闭环策略，供风热回收效率从恒速固定周期的 0.52 分别提高到 0.63 和 0.65：

- 按风量调转速：风道内装风量传感器，调整风扇转速，使两个方向的风量相等。
- 按温度调周期：转速不变，蓄热体两端装温度传感器，送风温度低于、排风温度高于「室内外温度平均值」时换向，周期随之变化。

不采纳：传感器要装进风道，带来结露、冷端补偿、抗干扰、容错和启动逻辑等一系列设计，而收益来自一次不受控的实测，在本项目的蓄热体和风道上不一定成立，收益不大但复杂度增加很多。

## 影响

- 翻转时风扇自行减速反转，期间实际风向与显示的目标风向有短暂偏差；切换时的电流冲击由风扇自己处理，控制层不考虑。
- 12V 接入后、C3 启动前，MOSFET 截止，控制线被风扇上拉，风扇全速进风；C3 启动后输出 50%，风扇停转。这段全速时间可以接受。
- 没有堵转检测，风扇卡住时系统无法发现。
- 三档占空比和停转区边界只在 12V、单台风扇、面包板上测过，不测其他电压和其他个体；低档已经为停转区留出余量。
- 成品板用的 2N7002 与面包板验证的 2N7000 不是同一颗，成品板上需要确认 PWM 波形。
- 数据手册只给出占空比 5% 以下（约 2750 转/分）和 43%（约 1000 转/分）两个工作点，都在低占空比一侧，没有反向侧的风量和噪声数据。其中 43% 工作点的最大风量 123 m³/h 反而高于 5% 工作点的 120 m³/h，数据存疑，风量和噪声不再实测。
- 两个方向的最大风量可能不同，往复模式下进气和排气的风量不对称。
