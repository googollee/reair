# 面包板验证电路设计

本文是面包板验证电路的设计文档，用来验证固件与硬件的配合。内容包括电路设计、器件和流程测试；不包含历史状态，也不包含最终开发板的内容。

成品板的原理图是 [`reair.kicad_sch`](reair.kicad_sch)。两者的区别：成品板带 PTC、反接保护、TVS、降压和 USB 插座，由 12V 单电源供电，使用 SMT 器件；本电路只验证风扇的 PWM 控制，开发板由 USB 供电，12V 只给风扇，使用直插器件。两者共用的是风扇控制的接法（GPIO 经 N 沟道 MOSFET 拉低风扇 PWM 线），其余不要互相套用。

## 器件

| 器件 | 说明 |
|---|---|
| ESP32-C3 开发板 | USB 供电，带 BOOT 键和 LED 的即可 |
| 12V 适配器 | 12V，风扇电压范围 9.5–12.6V |
| ebm-papst 4412FGPR 风扇 | 红 +12V，蓝 GND，紫 PWM |
| N 沟道 MOSFET | 直插 2N7000（TO-92），SOT-23 的 2N7002 不好插面包板 |
| 电阻 | 1k、100k 各一只 |
| 万用表 | 第 1 步用 |

## 接线

```
12V 适配器 + ───────── 风扇红
12V 适配器 − ──┬────── 风扇蓝
               ├────── MOSFET 源极
               └────── 开发板 GND（必须共地）

开发板 GPIO4 ── 1k ──┬── MOSFET 栅极
                     └── 100k ── GND
MOSFET 漏极 ────────────── 风扇紫（PWM）
```

- 2N7000 的 TO-92 引脚：平面朝向自己、引脚朝下，从左到右依次是源极、栅极、漏极（S-G-D）。
- BS170 常见排列是漏极、栅极、源极（D-G-S），与 2N7000 相反，直接替换会把源漏接反；onsemi 2021 年 12 月后的新版据称又交换了栅极和源极。本文只用 2N7000，换成 BS170 前必须查所用厂家的数据手册。
- 栅极上的两个电阻构成分压，栅极电压为 3.3V × 100k ÷ (1k + 100k) ≈ 3.27V。串联电阻要比下拉小得多，否则栅极电压偏低，2N7000 导通不充分。
- 1k 串联电阻给面包板连线的电感和栅极电容的振荡提供阻尼；边沿变慢的程度远小于 PWM 周期，不影响占空比。
- 开发板用自带的 BOOT 键（GPIO9）和 GPIO8 上的蓝色 LED，不需要另接按键和 LED。
- 12V 只给风扇，开发板走 USB。

## 固件

验证固件在 [`breadboard-fw/`](breadboard-fw/)，是独立的 ESP-IDF 工程，不含 Matter，也不使用 `firmware/`。在 GPIO4 上用 LEDC 输出 PWM，通过开发板的 USB 口提供命令行（提示符 `fan>`）：

| 命令 | 作用 |
|---|---|
| `duty <0-100>` | 设置紫线占空比（%） |
| `freq <2000-5000>` | 设置 PWM 频率（Hz） |
| `stop` | 中止扫描并设为 50%（停机点） |
| `sweep <起> <止> <步长> <毫秒>` | 扫描占空比，每步打印当前值 |
| `invert <0\|1>` | 开关 MOSFET 反相补偿，默认 1 |
| `led <0\|1>` | 设置 GPIO8（板载蓝色 LED）的电平，0 亮、1 灭 |
| `status` | 显示当前状态 |

`duty` 等命令的占空比都是紫线上的值。`invert=1` 时固件输出 `100 - 占空比`，抵消 MOSFET 的反相。上电后固件会尽早设为 50%，在此之前 MOSFET 截止，紫线被风扇上拉，风扇会短暂全速进风。

## 准备

1. **烧录固件**：在 `breadboard-fw/` 下按 ESP-IDF 的方式编译，然后用 `idf.py -p <端口> flash monitor` 烧录并连接串口。端口用 `ls /dev/cu.usbmodem*` 查。
2. **不接 12V 验证固件**：只接开发板 USB。在 `fan>` 提示符下输入 `duty` 和 `status`，用示波器或万用表直流档量 GPIO4，确认输出随 `duty` 变化。
3. **接线检查**：按上面的接线连好后，断开所有电源，用万用表蜂鸣档检查：
   - MOSFET 三个引脚没有接错（2N7000 是 S-G-D）。
   - 开发板 GND、MOSFET 源极、12V 适配器负极、风扇蓝线共地。
   - 12V 正极只连风扇红线。
4. **上电顺序**：先给开发板接 USB，等固件把 GPIO4 设成 50%，再接 12V。MOSFET 截止时紫线被风扇上拉，相当于 100% 占空比，先接 12V 风扇会全速进风。

## 验证步骤

1. **量 PWM 线开路电压**：先不接 MOSFET 漏极，风扇接 12V，紫线悬空，用万用表量紫线对蓝线的电压。数据手册只说输入是开集电极，没有给内部上拉电压。这个值只是记录，接法仍然通过 MOSFET。
2. **确认极性**：断开 12V，把 MOSFET 漏极接到紫线，再按准备里的上电顺序上电。GPIO4 输出 0% 和 100% 各一次，看风扇状态。GPIO 为高时 MOSFET 导通，把紫线拉低，所以预期输出是反相的。数据手册给的是紫线上的占空比：0%–50% 为排风，50%–100% 为进风。
3. **停转区**：以 1% 步进扫占空比，分别从两侧靠近中间，记下停转点和重新起转点，与[风扇控制 ADR](../docs/adr/0005-fan-control.md)中的停转区和滞回对照。
4. **三档标定**：对每个方向测高、中、低三档的占空比，与[风扇控制 ADR](../docs/adr/0005-fan-control.md)中的初值对照。
5. **翻转**：从一个方向切到另一个方向，经停机点（50%）停留不同时间，找出转子停稳所需的最短时间。
6. **频率**：2 kHz、3 kHz、5 kHz 各测一次，看转速和噪声是否有差别。

## 注意

- 数据手册没有给转速反馈线，转速只能靠听、看，或另用转速计。
- 2N7000 的栅极阈值最大约 3V，3.3V 驱动时导通电阻偏大，但这里负载只有开集电极上拉电流，影响不大。要是紫线低电平量出来明显高于 0.5V，再加驱动。
